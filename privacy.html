Política de privacidade

Política de privacidade

Data de vigência: 19 de junho de 2026

Quem te segue é uma ferramenta pessoal para analisar arquivos de exportação de conta selecionados pelo usuário.

O app não pede credenciais do Instagram, não faz login na conta do usuário, não coleta senhas, não usa cookies ou tokens de acesso, não raspa sites, não usa APIs privadas, não automatiza ações em conta e não monitora contas automaticamente.

Dados processados

Quando o usuário importa um ZIP, JSON ou HTML, o app processa localmente nomes de usuário de seguidores e perfis seguidos. O app cria registros processados contendo:

  • nomes de usuário normalizados;
  • contagens de seguidores e perfis seguidos;
  • data de importação;
  • rótulo de conta informado pelo usuário;
  • hash da origem usado para detectar importações duplicadas;
  • preferências locais de revisão, como perfis ocultos;
  • resultados de comparação entre importações.

O arquivo ZIP, JSON ou HTML original é lido a partir do local selecionado pelo usuário e não é persistido pelo app depois da leitura.

Armazenamento

O uso gratuito armazena registros processados localmente no aparelho.

Usuários Pro podem ativar sincronização pelo iCloud. Quando ativada, registros processados são armazenados no banco privado do CloudKit do usuário e contam contra a cota do iCloud do usuário. O desenvolvedor não opera banco de dados próprio para dados de seguidores.

O bloqueio local opcional usa autenticação do aparelho para desbloquear o app. O app não coleta, recebe, transmite nem armazena dados de Face ID, Touch ID ou código do aparelho.

Compartilhamento e rastreamento

O app não vende dados do usuário e não usa dados para rastrear usuários entre apps ou sites.

Esta versão não inclui SDK de anúncios. Se anúncios forem adicionados futuramente, esta política, as respostas de privacidade da App Store e as notas de revisão deverão ser atualizadas antes da publicação.

O app abre links públicos de perfil somente quando o usuário toca em um nome de usuário. Ele não busca dados de perfil dentro do app e não automatiza ações na conta do usuário.

O app não monitora contas em tempo real e não tenta determinar por que uma relação entre contas mudou. Os resultados representam comparações entre os arquivos selecionados e podem não refletir o estado atual de uma conta.

Exclusão

Usuários podem apagar importações individuais, apagar todos os dados locais, desativar a sincronização do iCloud e solicitar a exclusão de registros Pro sincronizados no iCloud em Ajustes > Privacidade e dados.

Privacidade na App Store

A implementação atual não tem banco de dados de seguidores hospedado pelo desenvolvedor, não tem SDK de analytics, não tem SDK de anúncios e não faz rastreamento entre apps ou sites.
